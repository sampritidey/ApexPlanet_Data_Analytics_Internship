# ApexPlanet Task 2 - Exploratory Data Analysis and Business Intelligence

## Project Overview

This project is part of Task 2 of the ApexPlanet Data Analytics Internship.

The project focuses on performing Exploratory Data Analysis (EDA), SQL-based business analysis, multivariate analysis, and dashboard development using a cleaned sales dataset.

## Objectives

* Analyze the cleaned sales dataset.
* Perform descriptive statistical analysis.
* Explore numerical and categorical variables.
* Identify sales patterns and trends.
* Answer business questions using SQL.
* Perform correlation and multivariate analysis.
* Create meaningful data visualizations.
* Develop a static business dashboard.
* Extract actionable business insights.
