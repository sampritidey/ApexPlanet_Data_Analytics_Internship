# 📊 ApexPlanet Data Analytics Internship Portfolio

## 👩‍💻 Internship Overview

Welcome to my **ApexPlanet Data Analytics Internship Portfolio**.

This repository is the master portfolio for my **60-Day Data Analytics Internship at ApexPlanet Software Pvt. Ltd.** The internship provided hands-on experience in the complete data analytics workflow, starting from data cleaning and exploratory analysis and progressing to deep-dive analysis, interactive dashboards, statistical validation, data storytelling, and final portfolio development.

The internship was completed through four major analytical tasks, followed by this final capstone portfolio.

The main objective of this internship was to develop practical skills in data analytics by working with a real-world dataset and applying an end-to-end analytical process.

# 📚 Key Learning Outcomes

This internship helped me understand how a data analytics project is developed from beginning to end.

### 1. Data Preparation

I learned how to inspect raw data, identify data-quality problems, clean the dataset, and prepare it for analysis.

### 2. Exploratory Analysis

I learned how to use statistics and visualizations to identify patterns, trends, and relationships within the data.

### 3. SQL for Business Analysis

I gained practical experience in writing SQL queries to answer business questions using filtering, aggregation, grouping, and joins.

### 4. Customer Analysis

I learned how customer-level metrics can be used to understand purchasing behaviour and create meaningful customer segments.

### 5. Dashboard Development

I learned how analytical results can be converted into interactive dashboards that make information easier to understand.

### 6. Statistical Validation

I learned how hypothesis testing and statistical measures can be used to provide additional support for analytical findings.

### 7. Data Storytelling

I learned how to transform technical analysis into a clear and understandable business story.

### 8. Professional Documentation

I improved my ability to organize analytical projects, document the workflow, and present results professionally using GitHub.
